🩺 About

CarePlus Hospital Management System is a simple and responsive hospital management project for handling patient records.

It supports patient registration, record viewing, patient search, deletion and local data storage.

🎓 Built as an educational/demo project.

✨ Features

🔐 Admin Login

🏥 Hospital Dashboard

➕ Patient Registration

📋 View All Patients

🔎 Search Patient by ID

🗑️ Delete Patient Record

💾 Local Storage

📊 Live Patient Count

📱 Responsive Design

💻 C File Storage Demo

🚀 Run

Web Application

cd CarePlus-Hospital-Management-System

Then open index.html in your browser.

C Program

gcc main.c -o hospital
./hospital

Records are stored in hospital.dat.
