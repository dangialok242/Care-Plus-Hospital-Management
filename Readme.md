## 📌 About The Project

**CarePlus Hospital Management System** is a web-based patient management application designed for simple and efficient hospital record management.

It provides an interactive dashboard for **patient registration, viewing records, searching patients, deleting records, and monitoring patient count**.

> This project is a **frontend-based hospital management system** and can be extended with databases, backend authentication, APIs and cloud technologies.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| 🔐 Admin Login | Hospital administration login |
| 🏥 Dashboard | Central patient management dashboard |
| ➕ Registration | Add patient information |
| 📋 All Patients | View registered patient records |
| 🔎 Search | Search using Patient ID |
| 🗑️ Delete | Remove patient records |
| 📊 Patient Count | Shows total patients |
| 💾 Local Storage | Stores records in browser |
| 💻 C Program | File-based patient storage demo |
